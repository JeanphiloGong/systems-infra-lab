Verdict: pass. Both versions satisfy their original roadmap scope; accepted
v0/v1 tutorials and the frozen SSTable implementation remain byte-identical.

value, preserves empty strings, and falls back for keys absent in newer files.
The guide explicitly defers persistent file-set discovery/manifests to v5 and
does not guess priority from filesystem timestamps. Printed create and reopen
commands run in separate processes and return the same latest values.

v3 now begins with an executable v2 failure: omitting the deleted key from the
new file returns its old value. The replay executes this snippet using the
printed v2 source in a temporary directory. Tagged JSON value/delete records
then prevent reserved-string collisions and stop searching at a tombstone.
The guide explains both encoding layers, rejects mixing v2 raw-value files
with v3 tagged files, and preserves arbitrary strings including empty values
and JSON-shaped text. A later put may override a delete as a new operation.

Tests exercise multiple-file priority, deletion, later recreation, empty
collections/files/values, malformed tags, invalid value types, separate-process
restart, and printed checkpoint create/reopen commands. Replay materializes
the embedded source into fresh directories; it does not copy current source
as a substitute for missing tutorial code.

source edit. The updated replay sets PYTHONDONTWRITEBYTECODE=1 before either
subprocess runs in its fresh temporary directory, preventing stale pyc creation.
