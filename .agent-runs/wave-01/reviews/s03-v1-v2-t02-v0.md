## Findings

## Verdicts

- S03 v1: pass. Frame boundaries, length complement, checksum, payload bound,
  incomplete tails, full-frame corruption, and the restricted append fault
  model are explained before code. Every incomplete second-frame prefix is
  checked; malformed complete frames fail instead of being silently skipped.
- S03 v2: pass. After-image assignments motivate replay idempotence, while
  candidates and pending transaction IDs explicitly lack committed status.
  The log-first branch is described as program order, not durable WAL order.
  Partial intent can violate the balance invariant and is not exposed as
  committed recovery.
- T02 v0: pass. The experiment moves only the first data read across the
  writer's commit and verifies a fresh read outside the snapshot. The guide
  does not overgeneralize the timing observation to all SQL commands.
