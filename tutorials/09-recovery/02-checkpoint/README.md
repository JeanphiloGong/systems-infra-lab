# A02：Checkpoint 与有界恢复

在 `main` 按各版正文逐步创建实验文件，先完成前置版本再运行命令。路径是创建目标；旧测试和 replay 脚本仅供 `reference` 对照。参见 [从零学习约定](../../../docs/learning-workspace.md)。

本模块按暂停写入的单写者模型逐步建立检查点。各版按正文创建文件并执行直接检查；过去撤回与后续修订的记录保存在进度文档，不作为你当前实现的验收状态。

- [v1：位置一致的快照](v1/tutorial.md)
- [v2：发布后回收日志](v2/tutorial.md)
- [v3：损坏快照回退](v3/tutorial.md)
- [模块计划](plan.md)

范围仍是暂停写入的单写者模型；不停写快照和完整 ARIES 不在本模块内。
