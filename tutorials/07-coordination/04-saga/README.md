# D04：Saga 与补偿

在 `main` 按各版正文逐步创建实验文件，先完成前置版本再运行命令。路径是创建目标；旧测试和 replay 脚本仅供 `reference` 对照。参见 [从零学习约定](../../../docs/learning-workspace.md)。

本教程把订单拆成预留库存、扣款、配送三个本地服务步骤。Saga 持久化每步状态，失败时逆序执行业务补偿；补偿失败进入 manual，而不是伪装成回滚。

- v0：中途失败留下部分效果。
- v1：SQLite 持久化步骤并支持重启续跑。
- v2：逆序、幂等补偿。
- v3：补偿重试、耗尽和人工处理。
- v4：并发订单按 order_id 隔离效果键，同时说明 Saga 的隔离限制。

这些是本地确定性模型，不宣称跨数据库原子性。每个版本都有完整 source fence，replay 测试会在临时目录提取并运行。
