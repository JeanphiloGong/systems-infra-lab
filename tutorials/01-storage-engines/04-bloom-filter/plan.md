# S04 总计划

目标：为大量不存在的商品键查询减少不可变文件扫描，保持所有真实查询结果。读者需要 Python 文件读写、位运算与概率基础。压缩模型从 TSV 基线开始，最终接入 S05 v1 的真实 SSTable；不构建完整数据库。

不变量：插入过的键无假阴性；可能存在继续真实查表；过滤器和文件对应且文件不可变；测量将构建成本与查询成本分开。普通 Bloom Filter 不支持直接清位删除。

1. v0 建立首尾缺失的扫描计数基线，完整 baseline.py。验收 1/3/3 次与空文件，规模 S。
2. v1 位数组、UTF-8 稳定 BLAKE2b 双哈希、重复插入、碰撞语义，完整 filter.py。验收强制假阳性且无假阴性，规模 M，依赖 v0。
3. v2 推导近似率并遍历 m/k/n，完整 filter.py+measure.py。验收八组合、理论/实测/分母/字节数、零假阴性，规模 M，依赖 v1。
4. v3 从真实 SSTable.items 构建，False 跳过、True 调用 get，完整 SSTable依赖+filter.py+table.py。验收相同结果、空值、强制误报仍读取、重开全部键正确、实际文件打开次数，规模 M，依赖 S05 v1 和 v2。

每步正文先说明已有行为的缺口，再给完整代码与独立执行检查。replay_s04.py 仅从正文抽取各版本文件到临时目录，不注入最终代码。先作者测试、独立审核、修复再验收；本轮不提交 Git。
