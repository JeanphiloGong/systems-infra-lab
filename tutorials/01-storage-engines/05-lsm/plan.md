# S05 模块计划

场景是频繁覆盖和删除同一键。逐步建立最新值可见、删除不复活、发布集合可恢复三条不变量。

1. v0/v1 建立字符串映射与不可变 JSONL；v2 按新到旧查询，v3 用标签区分删除与缺失。
2. v4 合并连续文件范围并按覆盖范围保留删除，v5 通过 MANIFEST 发布当前集合。
3. v6 在相同文件格式上接入 S03 framing、WAL 和 S04 ImmutableTable；验证先日志后确认、flush 发布顺序、新进程读回与损坏拒绝。
4. v7 给同一入口增加 full 与两层 leveled，断言 L1 不重叠并按实读文件计数。每次合并后重开，验证旧值、覆盖与删除。

各版 [正文入口](README.md) 给出完整文件及直接检查。put/get 的空字符串语义持续保留；v3 起 None 表示删除。限定本地 POSIX 单写者，不实现后台压缩、并发读者回收或完整多层调度。
