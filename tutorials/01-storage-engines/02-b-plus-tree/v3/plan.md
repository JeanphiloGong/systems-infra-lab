# S02 v3 写作计划

叶页增多后，根的分隔键也有容量。内部节点满时提升中间分隔键，左右两组继续保持子树范围；随机插入后逐步验证父子边界和叶深度。

前置：本模块 v2。以下任务依次进行，目标文档为 [tutorial.md](tutorial.md)。

1. 沿 v2 的递归插入把分裂继续传给父节点；内部节点溢出时提升中间分隔键，并拆分 children，保证子节点数=键数+1。
2. 每次插入后执行结构验证：键有序、父子范围相符、所有叶深度相同；用乱序键插到树高超过两层再逐键与字典对照。下一版增加有序范围遍历。
