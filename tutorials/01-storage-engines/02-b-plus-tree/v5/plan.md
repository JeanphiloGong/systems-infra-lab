# S02 v5 写作计划

内存结构必须变成可验证的页文件。每页固定 256 字节，元页记录 magic、版本、容量、根页号、页数和高度；叶页记录键值与 next 页号，内部页记录子页号与分隔键；每页尾部 CRC32。打开时按页号重建对象图，不重新插入键。依赖 v4；不提供崩溃原子性，不提前引入 WAL。

前置：本模块 v4。以下任务依次进行，目标文档为 [tutorial.md](tutorial.md)。

1. 在 page_file.py 编码固定 256 字节页：先为对象分配页号，再编码根、子节点、叶 next 引用，末尾保存 CRC；不要重插键来伪造拓扑恢复。
2. load 先验证长度、格式和页引用，再重建对象图。对照 save 前后的 get/range 与树高；分别截断一字节、翻转 CRC、注入非法键，验证拒绝且不覆盖已有目标文件。磁盘成功保存不等于崩溃原子性。

按正文给出的直接运行命令检查当前代码；reference 中的旧测试仅供对照。
