# S02 v2 写作计划

容量 3 的叶页放入第四个新键时，单页已经不能保持容量。把有序项从中间切成左右两页，用右页最小键作为父分隔键；根叶变为两子节点。等号必须走右子树，因为分隔键属于右叶。

前置：本模块 v1。以下任务依次进行，目标文档为 [tutorial.md](tutorial.md)。

1. 在 tree.py 的叶插入处保留 bisect_left 的覆盖语义；只有新增后超过 capacity 才按中点分裂。返回右页最小键与右页，父节点把它们插入对应槽。
2. 根收到分裂结果时建立新根。容量 3 插入第 4 个键后逐键 get，特别检查等于分隔键走右叶；覆盖原键不能产生额外分裂。冻结叶分裂，内部节点溢出留 v3。
