# S06 总计划

场景：订单报表按地区过滤并求金额和，只需要地区与金额而无需订单备注。前置 S01 的记录、字节布局与读取计数。最小模型是不可变订单 `(id, region, amount, note)`；地区允许 None，金额非负。核心不变量是所有布局和优化返回相同结果、统计范围不能排除真实匹配、缺失值保留。

1. v0：固定二进制行完成 region 过滤与 sum，报告读取字节/扫描字段。完整 rows.py；首尾、缺失地区、空输入、截断检查。规模 S。
2. v1：相同字段分成四文件，只读地区和金额；核对行存结果与字节差。完整 rows.py+columns.py；空列、长度不一致、选择列无额外读取。规模 M，依赖 v0。
3. v2：地区字典编码，None 保留专用 code；记录字典与 code 空间、解码一致。完整前置+dictionary.py；重复地区、空值、坏码。规模 M，依赖 v1。
4. v3：金额过滤批次 min/max 跳过；统计在写文件时生成并同一对象绑定，边界闭区间不漏读。完整前置+batch.py；首尾边界、空匹配、全部读取和跳过比较。规模 M，依赖 v2。
5. v4：同一数据报告扫描、点查和完整行更新的应用读写量/文件操作数；说明局部列更新与宽行读取权衡。完整 checkpoint 所需文件+workloads.py；结果一致、更新后重新查询。规模 M，依赖 v3。

每篇先出现具体负载压力，再增加一个机制；代码包含完整依赖，临时目录重放。使用标准库 Struct/JSON，文件仅实验自己创建。非目标：Parquet、压缩块、事务、多写者、向量化和物理磁盘基准。先行为测试再实现，完整检查后独立审核；不提交 Git。
