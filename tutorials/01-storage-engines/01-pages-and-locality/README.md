# S01：页、记录与访问局部性

在 `main` 按各版正文逐步创建实验文件，先完成前置版本再运行命令。路径是创建目标；旧测试和 replay 脚本仅供 `reference` 对照。参见 [从零学习约定](../../../docs/learning-workspace.md)。

订单服务按编号读取文件中的一条订单。先数清扫描读了多少字节，再增加直接定位、页、测量和有界缓存。前置知识只有 Python 函数、二进制文件和整数运算。

学习顺序：[v0 扫描](v0/tutorial.md) → [v1 偏移](v1/tutorial.md) → [v2 页](v2/tutorial.md) → [v3 工作负载](v3/tutorial.md) → [v4 缓存](v4/tutorial.md)。写作任务见 [plan.md](plan.md)。

代码创建目标是 `labs/storage/pages/`，参考测试位于 `tests/storage/pages/`。`reference` 分支保留此前的最终实现；每篇正文保留当时完整文件，可在独立临时目录重放。版本号只属于本模块，不是仓库发布版本。运行命令均从仓库根目录执行。

本实验文件只在生成后读取，不允许实验期间修改。应用报告的读取量不等于磁盘设备实际读写量；不实现数据库缓冲池、并发页锁或写回恢复。
