# F04 总计划

原始范围：docs/roadmap.md F04 v0-v3。目标是把同步到期的商品缓存请求变成可解释的在途任务调度，不用顺序循环伪装并发。

核心不变量：同键填充结果正确传播，等待者取消或超时不破坏其他等待者，源失败不会造成无限悬挂。可取消异步源和单事件循环是明确假设；同步阻塞函数、跨节点锁和生产吞吐不在本专题。

1. v0 建立过期基线与测量探针：20 个 Task 在 Event 前等待，实际 peak=20。
2. v1 引入在途映射：在 await 前登记，20 个请求只发出一次加载；保留取消问题供下一版修复。
3. v2 增加 shield、请求期限、源期限及完成回收：逐个运行取消、异常、超时和恢复轨迹。
4. v3 接入 TTL/SWR：比较多键同步/随机到期；观测旧读与硬到期；启动两个子进程暴露作用域边界。

每项任务的正文目标、验收与冻结条件见各版 plan.md。最后交付是四个可独立重建的源码检查点与严格正文回放。完成后由协调者独立审查；此任务不提交 Git、不改全仓库进度记录。
