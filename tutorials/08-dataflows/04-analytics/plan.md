# E04 总计划

场景：联合订单和客户来源生成销售分析。模型是源文件、批次水位、复制表、联邦附加库和查询计划。

1. v0 导入两个持久源并记录 batch/high watermark，核对聚合。
2. v1 以源主键和更新时间去重，迟到修改按源事实重算受影响客户。
3. v2 使用 SQLite ATTACH 直接查询源，选择性谓词命中源索引并报告远程匹配行数/计划。
4. v3 同时报告复制快照与联邦当前值，断开联邦源后保留复制结果并标记实时查询不可用。

每版源码 fence 在空目录独立执行。边界：小规模 SQLite 教学实验，不实现企业数仓调度、跨源事务、全局快照或完整联邦优化器。
